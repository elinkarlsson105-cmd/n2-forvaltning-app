# Fönsterkort — installationsguide

Se den fullständiga steg-för-steg-guiden i chattkonversationen med Claude.
Kortversion:

1. Skapa Supabase-projekt, kör `supabase-schema.sql` i SQL Editor.
2. Kopiera `.env.example` till `.env`, fyll i din Supabase-URL och anon-nyckel.
3. `npm install`, `npm run dev` för att testa lokalt.
4. Skapa GitHub-repo, pusha koden.
5. Koppla repot till Vercel, lägg in samma miljövariabler där, deploya.
6. Öppna länken på iPhone i Safari → dela-ikonen → "Lägg till på hemskärmen".
Uppdaterad.
